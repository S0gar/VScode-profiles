# VScode profiles

The project is a list of profiles that I find convenient to work with in Visual Studio Code.

## Installation

Select profiles settings

![where-is-profiles-prop](images\where-is-profiles-prop.png)

select import profile

![where-is-import-profile](images\where-is-import-profile.png)

and select the required profile from the directory where you downloaded the project

![where-is-select-dir](images\where-is-select-dir.png)

Congratulations, you’ve installed one of my profiles; repeat the process for the remaining files to get my complete Visual Studio Code setup.

## Profiles

At the moment, the project includes 3 profiles:
1. <img src="https://skillicons.dev/icons?i=vscode" height="25" align="center"> Default: This profile contains extensions 
that are common to all profiles, such as interface language, handy comments, icons, etc.
2. <img src="https://skillicons.dev/icons?i=cpp,cmake" height="25" align="center"> C++: Useful extensions for working with C++
3. <img src="https://skillicons.dev/icons?i=python,sklearn" height="25" align="center"> Data science: convenient extensions for working with machine learning and Python (Jupyter, Ruff, etc.)
